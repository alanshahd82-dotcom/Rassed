# راصد — Rassed

منصة تشغيل ثابتة لتتبع طلبات التجارة الإلكترونية للمغرب، جاهزة للنشر مباشرة عبر GitHub Pages.

الفكرة التشغيلية الأساسية في راصد هي أن الموظف يحدد العملية قبل المسح:

- **إرسال الطلبات**: باركود جديد ينشئ طلبًا بحالة `Sorti`.
- **استقبال المرتجعات**: باركود موجود بحالة `Sorti` يتحول إلى `Retour`.
- باركود مكرر أو طلب مغلق لا يُحتسب مرة ثانية.
- لا يمكن تسجيل مرتجع لباركود غير موجود.

## التشغيل

افتح `index.html` مباشرة في المتصفح أو انشر المجلد كما هو على GitHub Pages. لا توجد حزمة npm أو خطوة build. عند فتح الموقع عبر HTTPS سيظهر زر **تثبيت التطبيق** في المتصفحات الداعمة، ويمكن على iPhone استخدام Safari ثم «مشاركة» ثم «إضافة إلى الصفحة الرئيسية».

## البنية

- `index.html` — هيكل الشاشات ومسارات الواجهة.
- `styles.css` — نظام التصميم المتجاوب RTL.
- `theme-overrides.css` — طبقة الهوية البصرية والتحسينات المتجاوبة التي يمكن تعديلها دون لمس منطق التطبيق.
- `dataStore.js` — طبقة البيانات الوحيدة: بيانات تجريبية، البحث، الحالات، التنبيهات والإحصاءات. نقطة استبدال Google Sheets موضحة أعلى الملف.
- `app.js` — التنقل، العرض، التفاعل، اختيار عملية المسح، الماسح، التصدير CSV والإشعارات.

## ملاحظات

ماسح الباركود يستخدم `html5-qrcode` من CDN ويحتاج HTTPS وصلاحية الكاميرا عند فتحه على الهاتف. النسخة التجريبية تستخدم بيانات داخل الذاكرة ومهيأة لاحقًا لربط Google Sheets دون تغيير الواجهة.

## PWA

- `manifest.webmanifest` يعرّف اسم راصد وأيقوناته ووضع التشغيل المستقل.
- `sw.js` يخزّن واجهة التطبيق الأساسية لتعمل عند انقطاع الاتصال.
- `icons/` يحتوي أيقونات Android وiPhone بصيغة PNG.

## الهوية البصرية

الواجهة تستخدم خط Tajawal وطبقة ألوان تشغيلية تجمع بين الأزرق البحري والفيروزي، مع حالات واضحة للطلبات والتنبيهات، وتخطيط متجاوب للشاشات الكبيرة والهاتف. يتم تحميل طبقة التصميم الجديدة ضمن Service Worker لضمان ظهور النسخة المحدثة بعد النشر.
