# راصد — Rassed

منصة تشغيل ثابتة لتتبع طلبات التجارة الإلكترونية للمغرب، جاهزة للنشر مباشرة عبر GitHub Pages.

## التشغيل

افتح `index.html` مباشرة في المتصفح أو انشر المجلد كما هو على GitHub Pages. لا توجد حزمة npm أو خطوة build.

## البنية

- `index.html` — هيكل الشاشات ومسارات الواجهة.
- `styles.css` — نظام التصميم المتجاوب RTL.
- `dataStore.js` — طبقة البيانات الوحيدة: بيانات تجريبية، البحث، الحالات، التنبيهات والإحصاءات. نقطة استبدال Google Sheets موضحة أعلى الملف.
- `app.js` — التنقل، العرض، التفاعل، الماسح، التصدير CSV والإشعارات.

## ملاحظات

ماسح الباركود يستخدم `html5-qrcode` من CDN ويحتاج HTTPS وصلاحية الكاميرا عند فتحه على الهاتف. النسخة التجريبية تستخدم بيانات داخل الذاكرة ومهيأة لاحقًا لربط Google Sheets دون تغيير الواجهة.
