# راصد — تدقيق التوصيل

راصد نظام عملي لمتابعة وتدقيق طلبات شركات التوصيل للتجار. يساعدك على معرفة الطلبات الخارجة، المسلّمة، الراجعة، المتأخرة، والفروقات التي تحتاج إلى مراجعة.

## الوظائف

- لوحة متابعة لحالة الطلبات وأداء شركات التوصيل.
- تسجيل حركات `Sortie` و`Retour` باستخدام الباركود أو QR Code.
- منع تكرار تسجيل الحركة نفسها.
- بحث وفلاتر حسب رقم الطلب، المدينة، الحالة، وشركة التوصيل.
- مركز تنبيهات للحالات المتأخرة والفروقات والطلبات غير المعروفة.
- تحليلات وتقارير وتصدير سجل الطلبات.
- واجهة عربية متجاوبة مع الهاتف والكمبيوتر.
- دعم التثبيت كتطبيق على الأجهزة المتوافقة.
